# Pledge

Pledge protects freelancers from not getting paid on deals they already made outside any
marketplace. Clients secure each milestone with a PayPal hold; AI builds the plan and checks
deliveries. Built for the PayPal AI Hackathon 2026.

Full README (architecture, demo accounts, how to run) arrives in Phase 7. Until then see
[CLAUDE.md](CLAUDE.md) and [BUILD.md](BUILD.md).

```bash
npm install
cp .env.example .env.local
npm run dev
```
